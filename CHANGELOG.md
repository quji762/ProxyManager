# Changelog

Notable endpoint, restoration, security, and compatibility changes are recorded here. Fine-grained implementation history remains in Git.

## Unreleased

### Added
- A **Copy diagnostics** button in Settings: assembles version, OS, Python, language, schema version, persisted endpoint switches, the applied/residual ownership summary (no host, userinfo, password or proxy URL) and WSL availability into copyable text, so a bug report doesn't have to be hand-crafted (`js_api.py`, `ui/app.js`, `ui/index.html`).
- One-click **Copy URL** next to the proxy form: builds the current form address into a canonical proxy URL with the same percent-encoding the writers use (credentials included, since the point is pasting it into another tool) and copies it via the clipboard, falling back to the backend `clip.exe` helper. An invalid form address shows the localized error instead of copying a half-built URL (`js_api.py`, `ui/app.js`, `ui/index.html`).
- Keyboard shortcuts: digits **1–9** switch to the matching port preset (the chip tooltip shows its number) and **Esc** closes the port/preset popovers. Both are ignored while typing or while a dialog/settings pane is open, so normal text entry is never hijacked (`ui/app.js`, `tests/test_ui_shortcuts.py`).
- Tray menu now shows how many endpoints are currently enabled (derived from the applied record and persisted switches, never the form fields) and adds one-click **Enable all** / **Disable all**; both run on a background worker with balloon feedback so the tray never blocks (`tray_icon.py`).
- A one-click **Test all** button probes every channel of the visible lane concurrently, painting each result as it arrives, with a 45 s watchdog and a short in-page history of recent results (kept in memory only — never written to `config.json`) (`ui/app.js`).
- The Windows lane now shows a PAC caveat under the system-proxy row when an `AutoConfigURL` is registered: browsers may follow the PAC script, so the static proxy shown is not necessarily in effect. The hint is read-only and rendered as plain text (`ui/app.js`, `js_api.py`).
- Settings gained a persistent update-status row (last check result, re-check button, and an **Open download page** button when an update exists). The download button opens only the fixed repository releases page or the cached release URL — it accepts no caller-supplied URL. The status is kept in memory only (`ui/app.js`, `js_api.py`).
- **Named address presets**: save the current form (host / port / scheme / username / password) under a name and switch between whole setups with one click. Applying a preset reuses the port-switch migration, so only the endpoints currently enabled and managed by ProxyManager are re-applied and the `applied`/`restore` ownership semantics are unchanged. Preset passwords are DPAPI-encrypted on disk; the preset list never exposes the plaintext password (`config_store.py`, `js_api.py`, `ui/app.js`).
- **Config backup and one-click restore**: snapshot the current configuration into a managed `backups/` folder (newest first, capped at 30, atomic writes) and restore it from Settings. Restore deliberately routes through `save_config`, which never accepts the ownership records (`restore`/`applied`/`wsl_written`) from caller data — so a backup brings back form fields and preferences but cannot resurrect a stale applied record or make quit-clear claim the user's current proxy. Endpoints are left as-is and re-enabled by the user. Backup names are validated and confined to the backups folder (no arbitrary path read/delete); the backed-up password stays DPAPI-encrypted (`config_store.py`, `js_api.py`, `ui/app.js`).
- **Batch connectivity verdict**: after **Test all** settles (watchdog timeouts counted as failures), a toast reports `{ok}/{total} passed` — and `{fail} failed` when any channel failed — so the overall result is readable without scanning every chip. A **Clear** button beside the recent-results title empties the in-memory history for both lanes and appears only when the current lane has results (`ui/app.js`, `ui/index.html`).
- **Keyboard accessibility**: the confirm and Settings dialogs are proper modal ARIA dialogs with a focus trap, focus-on-open / restore-on-close and Escape-to-close; the Win/WSL tabs follow the tablist pattern with arrow-key roving focus; endpoint switches carry accessible names; and keyboard focus survives endpoint repaints (`ui/index.html`, `ui/app.js`).

### Changed
- Added build/packaging guards: `requirements.txt` must match `pyproject [project].dependencies`, `requirements-build.txt` must match the `[build]` extra, `.gitignore` must keep covering the sensitive config artifacts, and `APP_VERSION` must stay `x.y.z` (`tests/test_build_hygiene.py`).
- Documentation is consolidated into README, AGENTS.md and CHANGELOG.md.
- Proxy write/restore semantics, WSL networking rules and DPAPI constraints are now explicit agent invariants.
- `applied` is now only ever a real applied record: a config without it means ProxyManager has never written an endpoint, and the form address is no longer promoted into it (`config_store.py`). A plain save, a port quick-switch that migrates nothing and a legacy config therefore leave no record behind, so nothing is claimed as ours on quit-clear or quick-switch (`js_api.py`).
- PowerShell pre-enable snapshots are taken per environment variable name, covering every spelling an enable writes — both cases of `HTTP_PROXY`/`HTTPS_PROXY`/`ALL_PROXY` plus both `NO_PROXY` spellings (`js_api.py`). A restore deletes only the names enable actually wrote and no longer invents a `NO_PROXY` the user never had.
- Turning off "WSL writes to all user distros" now immediately removes this tool's shell block and Git/npm/pip entries from the distros that leave the scope; the default distro is never touched, and re-widening the scope no longer resurfaces a stale gateway address from a distro written earlier (`js_api.py`, `proxy_manager.py`).
- Port quick-switch results now surface the backend's notes (NAT gateway rewrite, PAC) and the per-endpoint failure reasons instead of a single generic line, and the "all distros" toggle reports whether the leaving-scope cleanup succeeded (`ui/app.js`).
- Performance: the `wsl -l -q` distro enumeration is cached for a couple of seconds (invalidated after `Restart WSL`), and a refresh coalesces its endpoint repaints into a single frame (`proxy_manager.py`, `ui/app.js`).
- Performance: the WSL availability probe (`wsl -e echo ok`) is cached for a few seconds so a batch "enable all" collapses its per-endpoint cold starts into one. Only a positive result is cached (a failure must not freeze "WSL unusable"), and `Restart WSL` invalidates it (`proxy_manager.py`).
- Switching the interface language now also repaints the dynamically generated test-history rows and backup-list buttons, not just static `data-i18n` nodes (`ui/i18n.js`, `ui/app.js`).
- The browser (no-bridge) mock now mirrors the real `js_api` contract — `get_config` carries the applied record / version / `wsl_written`, the system-proxy state is independent of PowerShell, and background preferences round-trip — so the fallback UI exercises the same ownership semantics as the backend (`ui/app.js`).
- Added a CI guard that fails if any shipped module adds a `subprocess` call without a real timeout (or with `timeout=None`), freezing the existing "every child process has a deadline" invariant so a wedged `wsl.exe`/`git` can never hang a worker forever (`tests/test_subprocess_timeouts.py`).
- Added a versioned config-schema migrator (`schema_version`, currently 2). The legacy `git` → `git_win`/`git_wsl` split and the old `speed_full` 5→40 default are now ordered, idempotent steps keyed off the persisted version instead of ad-hoc re-checks on every load. An upgrade is written back only when a real config file was read, so a corrupt config stays quarantined instead of being silently recreated (`config_store.py`).
- WSL distro enumeration now decodes `wsl -l -q` by BOM/NUL content instead of hard-assuming UTF-16LE, so a WSL build that emits UTF-8 is not mangled into NUL-interleaved or empty names (`proxy_manager.py`).
- Added direct unit coverage for previously-untested pure helpers (`_signed16`, `_bash_path`, `_ini_value_comment`/`_ini_strip_value`, `_mask_userinfo`) that underpin resize-coordinate handling, WSL path translation, INI parsing and credential masking (`tests/test_pure_helpers.py`).
- Added a Windows High Contrast (`forced-colors`) style block so the focus ring and control borders (chips, buttons, tabs, test chips) remain visible when the OS replaces the app palette; text inputs get an explicit system-colored focus outline instead of the border-only cue that disappears in that mode (`ui/styles.css`).
- Performance: a Windows-lane refresh no longer fetches the full config. `wsl_written` is consumed only by the WSL lane's NAT badges, so its `get_config` round-trip is now guarded to that lane (the WSL lane still fetches it before probing, so every check sees a fresh record) (`ui/app.js`).
- Performance: a batch connectivity test coalesces its history-list rebuild into one animation frame instead of rebuilding the whole list once per settled channel; the result row itself is still recorded immediately (`ui/app.js`).

### Fixed
- Test-chip and test-history failures, and the autostart toggle failure, now render through `msgText`, so a backend `error_key` is shown in the current UI language. `test_channel` returns keys like `errNoProxyToTest` / `errBadProxyUrl` / `errSocksNeedsCurl`; the chip and history previously showed the raw Chinese `error` string even in English mode (`ui/app.js`).
- Switching the interface language now also repaints the PAC hint and the speed caption immediately. Both are generated from `t()` at render time (not `data-i18n` nodes), so previously they kept the previous language until the next refresh or 1 s speed tick (`ui/i18n.js`, `ui/app.js`).
- A BOM-less UTF-16 `.npmrc` / `pip.conf` is now detected by which byte of each pair is NUL (LE vs BE), instead of being decoded as UTF-8 with interleaved NULs. Previously every key failed to match and the tool appended a duplicate line instead of editing the real one; the encoding is reused on write so the file stays BOM-less in the same byte order. Added tests for BOM, BOM-less UTF-16 LE/BE, CRLF, empty files and duplicate keys (`proxy_manager.py`, `tests/test_ini_edges.py`).
- `crash.log` no longer receives a subprocess exception's argv. `log_exception` / `log_crash` now log only the exception type for `subprocess.SubprocessError`, whose `str()` embeds the full command line — including the proxy URL with `user:pass@`. The type and traceback are still recorded for diagnosis, so a wedged `wsl.exe`/`git` stays debuggable without writing the credential to disk (`proxy_manager.py`).
- Port-switch rollback failure no longer orphans an endpoint this tool turned on. When a phase-2 re-enable fails and the rollback disable of an already-switched endpoint also fails, that endpoint is left holding the NEW address while `applied` deliberately stays on the old one. The actually-written new address is now recorded as a per-target `residual` record (DPAPI-encrypted password, validated like `applied`), so quit-clear and a later disable still recognize and remove it, and a later enable no longer stashes our own URL as user state. The ps/npm/pip disable path unsets the residual address (not the stale applied one) when the detected value really is the residual; a successful toggle or switch clears the record (`js_api.py`, `config_store.py`).
- Enabling an endpoint is now aborted before any write when the pre-enable stash cannot be persisted (DPAPI failure or a failed config write). Previously the failure was only logged, so the endpoint was overwritten and the user's original value was lost on exit; the error reaches the UI instead (`js_api.py`).
- Windows system proxy: a `ProxyServer` Windows leaves in the registry after the user turns the proxy off in the Internet Options UI (`ProxyEnable=0`) is now stashed and written back verbatim on disable, without re-arming the proxy. ProxyManager's own leftover is never stashed (`js_api.py`, `proxy_manager.py`).
- WSL Git/npm/pip: when a multi-distro enable fails on one distro, the distros already written are rolled back to their snapshotted user values instead of only unsetting ProxyManager's URL. A snapshot that cannot be read fails that distro rather than overwriting a proxy that was never snapshotted (`proxy_manager.py`).
- `Restart WSL` gateway rewrite checks each write's return value. A failed endpoint keeps its previous written-URL record — so quit-clear still claims it and the stale proxy does not survive in the user's distro — and the failure is reported instead of being recorded as a success (`js_api.py`).
- Port quick-switch partial failure now rolls the WSL Git endpoint back by the URL actually present in the file (the gateway form just written) instead of the typed loopback address, so a `--fixed-value` unset no longer silently no-ops and leaves the abandoned port in the distro. A rollback that itself fails is reported (which endpoint and why), and endpoints still holding the new address are listed (`js_api.py`).
- Scope-narrow cleanup now reads the distro git/npm/pip configs back after disabling: an endpoint whose recorded URL is still present — or whose distro cannot be read — keeps its written-URL record, so a later quit-clear can still claim the residue instead of orphaning it (`js_api.py`, `proxy_manager.py`).
- The multi-distro npm/pip WSL rollback also fires on a subprocess timeout: `TimeoutExpired` is not an `OSError`, and catching only `OSError` let a timed-out enable skip the rollback of the distros already written (`proxy_manager.py`).
- Disable ownership: the surgical PowerShell/npm/pip disable guard now compares against the address ProxyManager last applied rather than the currently detected value, so a proxy the user manually changed after enabling is no longer deleted when the endpoint is disabled (`js_api.py`).
- Verbatim restore: a stashed string URL is written back exactly as saved (a `raw_url` path through the Git/npm/pip setters) instead of being normalized through `build_proxy_url`, which downgraded `https`→`http` / `socks4`→`socks5` and dropped the path (`proxy_manager.py`, `js_api.py`).
- `boot()` no longer promotes the form address into the applied record when no applied record exists, matching the restore path; a legacy config therefore cannot make quit-clear or quick-switch claim a proxy the user set themselves (`ui/app.js`).
- An empty proxy value line is no longer mistaken for ProxyManager's and deleted: the INI disable guard matches only when the current value equals the written URL (`proxy_manager.py`).
- Concurrent same-process writes to one config file no longer truncate each other (the atomic-write temp name carries a uuid), and the clipboard helper times out instead of blocking a worker thread when the clipboard is busy (`proxy_manager.py`, `js_api.py`).
- WSL Git/npm/pip atomic writes now resolve a symlinked dotfile (stow/chezmoi/dotbot) to its real target before the `mktemp` + `mv -f`, so the rename lands on the target and the user's symlink survives. Previously `mv -f` onto the link replaced `~/.npmrc` / `pip.conf` with a regular file and stranded the dotfile layout — the same reason the shell-block path writes THROUGH the file (`proxy_manager.py`).

### Security
- Subprocess errors no longer leak credentials: `TimeoutExpired`/`CalledProcessError` embed the full argv (including credentialed proxy URLs) in their `str()`. These are now rendered as fixed localized messages across the WSL/Git/npm/pip error paths, so passwords cannot reach the UI, screenshots or logs (`js_api.py`, `messages.py`).
- `crash.log` is hardened against log injection and embedded secrets: a non-subprocess message that embeds `scheme://user:pass@` has its userinfo redacted, and CR/LF are escaped so an exception message cannot forge an extra log record (`proxy_manager.py`).
- Port presets are HTML-escaped on render: port values come from `config.json` / restored backups and may be arbitrary strings; they are now escaped in both attribute and text slots, closing an HTML-injection vector (`ui/app.js`).
- Background images are confined to local files: `save_config` / `get_background` reject UNC and device paths so loading a background cannot trigger SMB authentication (an NTLM-relay surface) (`js_api.py`, `proxy_manager.py`).
- Restore hardening: a PowerShell stash that fails to decrypt keeps its `DPAPI:` marker so restore falls back to surgical disable instead of treating every environment variable name as a user value to delete; the system-proxy restore validates the stashed URL and refuses to write a malformed `ProxyServer` (`js_api.py`).
- `switch_port` no longer backfills a managed URL from the form when there is no valid applied record, so a hand-configured proxy at the same address is not misclaimed as ProxyManager's (`js_api.py`).
- `esc_` now also escapes the single quote (`'` → `&#39;`), so an escaped value is safe in single-quoted attributes and inline handlers too, not only the double-quoted/text-node contexts used today. Contract tests assert the escape map covers all five HTML metacharacters and that the history rows and endpoint cards escape their dynamic fields (`ui/app.js`, `tests/test_ui_i18n_xss.py`).

## Current baseline

### Added
- Independent Windows and WSL proxy endpoints for shell environment, Git, npm and pip, plus Windows WinINET system proxy.
- HTTP/SOCKS5/SOCKS5H support, port presets and per-source connectivity checks.
- WSL2 NAT gateway rewriting and mirrored-network loopback handling.
- Live state synchronization, tray integration, autostart, themes and optional clear-on-quit.

### Safety
- Existing different proxy values are stashed before overwrite and restored on disable where possible.
- Endpoint switches reflect detected system state rather than assuming writes succeeded.
- Proxy passwords use Windows DPAPI and are not saved if protection fails.
- `NO_PROXY` updates preserve existing user entries.
